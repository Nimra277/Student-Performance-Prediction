Student Performance Prediction and Analysis System

Project Overview

This project focuses on analyzing student performance and predicting examination scores and placement status using Machine Learning techniques.

Dataset Information

- Total Records: 10,000 students
- Total Features: 8

Dataset Features

- study_hours
- attendance
- sleep_hours
- internet_usage
- assignments_completed
- previous_score
- exam_score
- placement_status

Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- SQLite
- Git and GitHub
- PyTorch

Project Implementation

1. Data Loading and Exploration
2. Data Preprocessing
3. Mathematics and Statistics
4. Data Visualization
5. Machine Learning and AI
6. Database and SQL
7. Version Control
8. Deep Learning

Machine Learning Models

- Linear Regression
- Random Forest Regression
- Logistic Regression
- K-Means Clustering
- Naive Bayes Classification

Project Objectives

- Analyze student academic performance.
- Predict examination scores.
- Predict student placement status.
- Identify student performance groups.
- Analyze relationships between student features.

Project Status

The project is being developed using Python and Google Colab.
